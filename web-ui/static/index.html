Model Armor & Apigee Demo: Text, Documents, and Multi-modalities — Architecture

          Apigee X
        

        
      

      

        

          
          
        

        

          
STEP 1
Verify the app
Apigee checks the caller's API key; the key stays on the server and never reaches the browser.

          
STEP 2
Screen input
Native: Your app extracts file text first; built-in policy screens text.
Callout: Your app sends raw PDFs, Office files & images; Apigee calls REST per part.

          
STEP 3
Screen answer
Only clean inputs reach Gemini. Outbound text and generated images are screened too — blocked (400) or redacted (200).

          
AUDIT
Log the decision
Mode, verdict, and matched filter names go to Cloud Logging (503 if unscreened). Prompts and files are never logged.

Screen a document vs Screen any modality

          Which one?
        

        
      

      

        
Both views send a file through Apigee to Model Armor before Gemini sees it. They differ in what you can send and how much of it gets screened.

        

          

            
At a glanceScreen a documentScreen any modality

            
              
Apigee modesNative policy and REST callout, side by sideREST callout only

              
Pictures, Word, Excel, PowerPoint❌ Not accepted✅ Accepted and screened

              
Pictures inside a document❌ Not screened✅ Screened (up to 5 per document)

              
Gemini's answer❌ Not screened✅ Screened; images blocked or redacted

              
Proxy and templateapigee-model-armor-101-proxy · text-only templatemodel-armor-multimodal-proxy · text and image template (us, eu or global)

Native policy vs REST callout

          Two ways to call Model Armor
        

        
      

      

        
Both send the prompt to the same Model Armor template and give the same verdict. They differ in how Apigee makes the call and how much you control.

        

          

            
At a glanceNative policyREST callout

            
              
How Apigee calls itBuilt-in SanitizeUserPrompt policyServiceCallout to the Model Armor REST API

              
SetupOne policy: template + where the prompt isCallout + JavaScript to build the request and read the reply

              
What it can screenText onlyText, and PDF, TXT or CSV files

              
ControlFixed behaviour, results in flow variablesFull JSON reply: custom checks and error handling

              
LatencyLowestSlightly higher: one extra HTTP call

              
In this demox-armor-mode: nativex-armor-mode: callout (same proxy)

            
          

        

        

          

            
🧩 Native policy

            
Apigee's built-in policy calls Model Armor for you.

            

              

                Native
                Appprompt→
                Apigeebuilt-in policy→
                Model Armortemplate→
                Gemini
              

            

            

              
Best for
Text prompts with the least setup.

              
Limit
Text only; files must be turned into text first.

            

          

          

            
🔌 REST callout

            
Apigee calls the Model Armor API itself and reads the reply.

            

              

                Callout
                Appprompt or file→
                Apigeecallout + JS→
                Model ArmorREST API→
                Gemini
              

            

            

              
Best for
Files, custom logic, or API fields the policy hides.

              
Cost
More policies to maintain, a little more latency.
