Model Armor and Apigee Demo — Architecture

          Apigee X
        

        
      

      

        

          
          
        

        

          
STEP 1
Verify the caller
Apigee checks the app's API key. The browser never sees it; this app's server adds it.

          
STEP 2
Screen the prompt
Model Armor checks the prompt for injection, harmful content, bad URLs and sensitive data. Native uses the built-in policy; Callout calls the REST API.

          
STEP 3
Forward to Gemini
Only clean prompts reach Gemini 2.5 Flash-Lite. A match returns 400; if Model Armor can't answer, Apigee returns 503 and nothing is forwarded.

          
AUDIT
Log the decision
Mode, verdict and matched filter names go to Cloud Logging. Prompt text is never logged.
