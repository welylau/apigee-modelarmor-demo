Architectural Insight: Model Armor Streaming vs Non-Streaming Tradeoffs

🛑 Non-Streaming (Buffered)

  • Mechanism: Apigee buffers the entire LLM response in memory before returning anything to the client.
  • Security Guarantee: Zero Token Leakage. If Model Armor triggers a policy violation, Apigee terminates with HTTP 400 Bad Request. The end user never sees any part of the offending response.
  • Tradeoff: Higher Time-to-First-Token (TTFT) and latency; not suitable for real-time chat UX.

⚡ Streaming (SSE with EventFlow)

  • Mechanism: Apigee opens a text/event-stream connection immediately. Chunks are evaluated in-flight within an EventFlow.
  • Security Behavior: When the safety violation threshold is crossed, Model Armor halts the stream and sends an SSE fault event.
  • Tradeoff: Low latency and superior user experience, but partial tokens can reach the client before the filter detects the violation and cuts the stream off.
