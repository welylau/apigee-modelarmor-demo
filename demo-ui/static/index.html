Apigee X + Model Armor Architecture

                    Zero-Trust LLM Guardrails

                        STEP 1
                        
Web UI & Dual Ingress

                        
Comparative workspace sends parallel prompts to buffered & streaming endpoints with x-inbound and x-outbound policy headers.

                    

                    

                        STEP 2
                        
Apigee X Gateway

                        
Evaluates header flags (AM-Set-Guardrail-Flags), mints GoogleAccessToken natively, and routes traffic via HTTP or Server-Sent Events.

                    

                    

                        STEP 3
                        
Model Armor Inbound (SUP)

                        
SanitizeUserPrompt intercepts Prompt Injections and Jailbreaks in ~750ms against ma-ai-gw-inbound with 0 tokens sent to Vertex AI.

                    

                    

                        STEP 4
                        
Gemini 2.5 Flash Lite

                        
Foundation Model in us-central1 generates multimodal inference via :generateContent (REST) or :streamGenerateContent (SSE).

                    

                    

                        STEP 5
                        
Outbound SMR & Forensics

                        
Guarantees Zero-Token Leakage on REST and In-Flight Cutoff on SSE. PostClientFlow records forensics to Cloud Logging.
